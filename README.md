# FriendNotifier Chrome Extension

## Installation

1. **Download the repository**
   - Clone this repository or download it as a ZIP file and extract it to a folder on your computer

2. **Install in Chrome**
   - Open Chrome and navigate to `chrome://extensions/`
   - Enable "Developer mode" by toggling the switch in the top-right corner
   - Click the "Load unpacked" button
   - Select the folder containing this extension (the folder with `manifest.json`)

3. **Done!**
   - The extension should now be installed and active in your Chrome browser
